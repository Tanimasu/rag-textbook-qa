JSON 备份包含问题、回答、引用和收藏，下载到你选择的位置。恢复时只新增记录，相同编号保留当前浏览器的版本。

对话与反馈如何保存

完整返回的问答及引用自动保存在当前浏览器，刷新后恢复当前显示的记录；停止或断流的片段不自动保存。访问口令不写入历史记录。主动提交反馈时，服务端另行保存本次问题、回答、引用、耗时和反馈内容，不保存 IP 或访问口令。历史记录中的旧回答不能再次提交反馈。未通过验收的实验功能在公开版中关闭。
