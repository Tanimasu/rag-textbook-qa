## 已完成的代码

新增 `rag/supplement.py`，只处理既有原文和段落编号，不创建模型客户端。模型不能提供替换正文，程序检查来源身份、连续段落、原文偏移和长度，追加时保留基线来源及编号。所选段落不能完整装入预算时明确拒绝，不截取半段。代码围栏、HTML 和 Markdown 表格、图片开头的段落均不参与正文选择。

离线回放新增 `compact_parent` 方案：同一二级节前后两个片段，跳过习题，最多取各片段开头两个连续正文段落。新增正文最多 1200 字符、最多 8 份来源，并遵守原有 4000 字符总预算。这只是实验工具的选项，未启用为产品默认策略；它仍可能补入与问题无关的正文。

选择器对栈题返回空结果，仍漏掉已知的递归工作栈证据，因此本次不据此更换产品默认策略。

第一轮阅读时把 Cache 回答中的“预读策略”视作疑点；逐字核对来源 7 后确认教材也使用这一名称，撤销该疑点。模型核证也可能把合理推断判为无依据，其分数是筛查材料，不是专家正确率。
