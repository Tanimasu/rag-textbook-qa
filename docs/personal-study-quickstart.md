# 每天用它学一节

已经配置好环境和教材索引时，运行 `rag-qa serve`，打开 <http://127.0.0.1:8000>。
尚未配置时，先按 [README 快速开始](../README.md#快速开始) 准备。日常使用聊天页即可。

1. **先问一个具体问题。** 选择教材，输入概念、区别或原理。例如“进程和程序有什么区别？”
   每次提问独立检索；需要比较时，把要比较的对象写在同一道题里。
2. **对照原文再采纳回答。** 点击资料编号或“对照原文”，核对结论有没有教材依据。
   原文不足、引用异常或有矛盾时，先看提示和片段；回答不等于已经核实的标准答案。
3. **写一句自己的理解。** 点击“学习笔记”，记下要点、疑问或易错处，再点击“保存笔记”。
   看见“笔记已保存”后，内容才进入历史库；草稿暂存失败时，先保存或“导出草稿（含原问答）”。
4. **收藏明天要回忆的题。** 在“历史与收藏”点击“复习收藏”，先回忆，再“显示回答与引用”。
   按实际情况选“还不熟 · 明天复习”或“已熟悉 · 一周后复习”。跳过和结束不记次。
5. **整理并备份。** 用教材、关键词、“只看收藏”或“有学习笔记”缩小范围，再按用途下载。

| 想做什么 | 选哪个功能 |
| --- | --- |
| 留下当前题及来源 | 回答下方“保存问答（含来源）” |
| 整理一组题的回答、引用和已保存笔记 | “导出筛选结果（Markdown）” |
| 先做题，再翻看回答 | 勾选“练习版”后导出；全部问题在前，已保存回答在后 |
| 换设备、换浏览器或留可恢复副本 | “备份与恢复”中的 JSON 备份；到目标浏览器选择文件并确认合并恢复 |
| 留下尚未保存的笔记文字 | 编辑器里的“导出草稿（含原问答）” |

导出后请确认下载文件已保存。Markdown 供阅读整理，恢复历史使用 JSON。
查看已有历史、写笔记、复习和导出不重新生成回答；提问仍按应用配置调用模型。

历史保存在当前浏览器、当前网址来源；不同端口、`localhost` 与 `127.0.0.1`、不同浏览器之间各自独立。
日常尽量固定同一入口。换了网址看不到旧记录时，先回到原入口；需要迁移时手动备份、恢复。
“清空对话”只收起显示，记录仍在历史面板中；“删除记录”和批量清理会真正删除。

提问草稿和笔记草稿只在当前标签页临时存放。出现暂存失败提示时，先复制提问文字，或保存 / 导出笔记；
浏览器支持时，刷新或离开页面前会提醒。不要把临时草稿当作备份。
