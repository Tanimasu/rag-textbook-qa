## 2026-09-17：BM25 初始基线

- 题集：`data/evaluation/product_acceptance_v1.json`，15 题，每本教材 3 题；
- 索引：五本教材共 5,700 个分块；
- Embedding 指纹：`467fe9dbfadd3d81b2ffcbda83d8ac4275c494afc392ca2a1222e3b746c2f074`；
- 参数：BM25，Top 5，上下文预算 4,000 字符；
- LLM 调用：无；
- 远程 Worker：运行前健康检查超时，因此没有运行 Embedding、Hybrid 或 Hybrid + Reranker。

BM25 没有精确命中标注章节的 5 题：

- `candidate-v1-01`：操作系统，位示图法；
- `candidate-v1-04`：计算机组成原理，海明校验；
- `candidate-v1-05`：计算机组成原理，补码减法转加法；
- `candidate-v1-09`：计算机网络，停止等待协议的重复分组；
- `candidate-v1-13`：数据库，参照完整性。

这只能说明纯字面检索在这些问法上存在缺口。必须等同一索引、同一题集上的 Embedding、Hybrid 和
Hybrid + Reranker 结果完成后，才能判断默认检索路径是否覆盖这些问题；当前不得据此调参或改题。

## 2026-09-17：逐题证据复核

在运行生成评测前，逐题对照冻结题集中的教材行段，15 题的问题、教材、标注章节和证据文件均保持不变。
复核修正了 3 条答案要点：

- `candidate-v1-02`：删除原文未明确支持的“简化文件系统管理”，改为教材明确陈述的隐藏物理几何、
  减少布局变化对驱动程序的影响；
- `candidate-v1-07`：修正“不同掩码一定得到不同网络地址”的错误；教材示例明确表明结果可能相同，
  但网络位与主机位的划分仍不同；
- `candidate-v1-15`：补充函数依赖必须是业务语义下所有合法关系都满足的约束，不能只看当前数据实例。

这次修改发生在 RAGAS 和答案生成验收之前，不涉及检索参数。问题文本和 `relevant_sections` 未变化，
因此上面的 BM25 检索指标仍然有效；未来的回答质量结果必须使用修正后的答案要点。
