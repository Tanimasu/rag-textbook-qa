# 本机教材导入向导

使用默认的 `rag-qa serve` 在 `http://127.0.0.1:8000` 运行后，点击“导入教材”，或访问 `/imports`。
第一版支持五本已有教材的 **UTF-8 Markdown（.md）和已有分块 JSON（.json）**，单个文件最多 8 MB、
单次最多 20000 个片段。PDF 仍先使用项目现有解析工具转成 Markdown，再从页面导入。
分块 JSON 可使用自定义 ID；带 `_p数字` 后缀时支持按此顺序翻阅原文，
UUID 等不含顺序的 ID 只提供准确定位的片段，页面会说明无法继续前后阅读。

1. 选择目标教材和文件，点击“上传并解析预览”。这一步不调用模型，也不改索引。
2. 核对解析得到的片段数、章节及前三个片段预览。带 BOM 的 UTF-8 文本会先规范化后解析，原始字节另行保留。
3. 勾选“确认建立或替换所选教材的索引”，再点击建立索引。
4. 页面显示实际完成的分块数。全部向量化后还要发布索引；只有发布成功才显示完成。
5. 返回聊天，选择新教材即可使用。服务会按已有版本检查机制刷新教材目录和检索缓存。

建索引使用当前配置的 Embedding 模型，可能调用配置的远程 Worker，不调用 LLM。
验证使用临时索引和假的 Embedding，不读取模型密钥、不访问远程 Worker 或付费 API。
原文阅读、观察台和聊天已用真实 Chroma 临时索引串联验证。

## 保存与恢复

默认保存在 `artifacts/product/imports/<任务编号>/`；自定义索引路径时则在索引目录同级的
`product/imports/` 下。页面会显示实际绝对路径。每个任务独立保存：

- `source.md` 或 `source.json`：原始上传字节；
- `parsed.md`：Markdown 去掉 UTF-8 BOM 后的解析输入（仅 Markdown 任务）；
- `chunks.json`：经过字段校验的分块；
- `job.json`：教材、文件散列、预览、实际批次进度和任务状态。

原教材和历史 `data/chunks/` 不覆盖。任务开始后关闭页面不会取消执行；当前浏览器标签页会记住任务编号，
刷新可继续查看。新标签页也可在“最近导入任务”选择最近二十条任务，继续查看进度。
服务重启后，未确认完成的任务显示“已中断”，保留上传与分块，检查教材列表后可重试。
失败也保留文件供检查，页面不展示模型错误或本机异常细节。预览后的分块内容变化会阻止建立索引。
页面导入和命令行建索引都拒绝重复 JSON 字段、NaN / Infinity 和数值溢出；检查在 Embedding 调用及集合替换前完成。

向量化沿用临时集合及发布机制：失败构建不替换已发布索引。页面重复提交同一运行中或已完成的任务
不会再启动一遍。一个服务同时只建立一个导入任务，已有跨进程教材锁继续生效。
未完成任务请先等待或检查进度；不在页面提供强行终止原生推理的按钮。

## 使用边界

默认只在本机监听且未使用 `--public` 时启用；对外监听的服务不提供导入接口。接口同时检查本机连接、
本机网址和浏览器来源，并沿用访问口令。任务进度有独立读取限额，不消耗提问次数或每日生成额度。
本版不提供 PDF 页面内解析、任意新教材命名、原始导入文件自动清理或断点续建。
可在“最近导入任务”清理结束后的上传、分块和进度副本，删除前会确认；运行中不能清理。
清理导入副本不会删除已发布索引。更换目标教材或文件会让旧预览失效，必须重新解析核对后才能建索引。
页面会忽略过时的进度响应，避免慢响应把已经切换的文件或任务重新显示出来。
