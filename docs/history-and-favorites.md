# 历史问答与收藏（第一版）

日常使用入口为 `rag-qa serve` 的聊天页。页面顶部新增“历史与收藏”，无需额外配置或模型调用。
Streamlit 仍作为调试工作台，本版历史功能只在 FastAPI 聊天页提供。

## 使用

- 选择教材提问，服务完整返回结果后，回答下方显示“已保存到此浏览器”。
- 刷新当前标签页会恢复正在显示的已保存问答；新开标签页默认展示最近十条，完整记录在历史面板中。
- 可搜索问题、回答、教材名、章节和引用原文；空格分隔的多个关键词需要同时匹配。
- 教材筛选和“只看收藏”可以与关键词搜索叠加。列表按保存时间倒序，每批显示二十条。
- 点击“查看原回答”会显示当时的回答、提示、耗时及引用快照，沿用引用跳转、复制和 Markdown 导出。
  这不会重新检索或生成，即使教材索引发生变化，也仍展示当时保存的公开片段。
- 收藏按钮可以再次点击取消收藏。“清空对话”只收起当前显示，刷新也会保持收起；记录仍在历史面板中。
- 单条“删除记录”会删除问答及引用快照。“清理记录”可批量删除未收藏记录，或删除包括收藏在内的全部记录。
  删除前有确认，删除后无法撤销；筛选条件不会缩小批量清理范围。

## 数据保存位置和范围

问答数据保存在**当前浏览器的网站存储 IndexedDB**，数据库名 `rag-qa-history`，版本 `1`，
对象仓库 `records`。不在项目目录或服务端 SQLite 中保存历史，因此不需要维护新的服务器数据库。
同一浏览器配置下的同一网址来源共享历史；`localhost` 与 `127.0.0.1`、不同端口、不同浏览器或设备
各自独立。同一浏览器配置的使用者都可以查看这些记录，服务访问口令不会隔离本机历史。

每条记录包含随机编号、保存时间、问题、教材编号和名称、收藏状态，以及公开结果快照：
回答、状态、提示、引用片段、冲突提示、引用编号检查、耗时和执行位置。
不保存访问口令、请求头、模型提示词或用于提交反馈的短期 `answer_id`；旧记录不再提供反馈按钮。
已返回的“仅教材片段”“无证据”和失败结果也会保存状态；主动停止、网络中断和 SSE 错误留下的部分回答不保存。

当前标签页正在显示的记录编号放在 `sessionStorage` 的 `rag-qa-visible-history` 中；
它只控制刷新时显示哪些记录，不包含问答正文。既有访问口令和教材选择仍使用原来的会话存储。

浏览器无痕模式、网站存储限制、磁盘空间不足或清除网站数据都可能影响保存。读取失败时页面会提示，
仍允许提问；写入失败时回答下方会明确显示“未能保存历史记录”，提供重试保存及原有的 Markdown 导出。
重要问答可以单独导出包含引用的 Markdown，也可以使用“备份与恢复”下载完整 JSON 备份。
本版没有自动跨设备同步。

## 整库备份与恢复

在历史面板展开“备份与恢复”，可备份全部记录，或只备份当前关键词、教材和收藏筛选的结果。
导出的 JSON 包含问答、引用、收藏和来源位置，不包含访问口令、模型提示词或短期反馈编号。
文件下载到浏览器选择的位置，可以手动复制到另一台设备恢复。

选择 JSON 备份后先校验并预览记录数量，点击“确认合并恢复”才会写入。相同编号保留当前浏览器版本，
不会覆盖已有回答或收藏状态；重复恢复不会产生副本。单次最多 5000 条、64 MB，记录较多时按教材筛选分批备份。
无效记录、重复编号、不支持的备份版本会拒绝整批文件；写入采用单个事务，空间不足等失败不会留下半份新增记录。
备份本身不认证回答质量或来源真实性，请只导入自己信任的文件。

备份格式为 `format="rag-qa-history"`、`version=1`、`exported_at` 和 `records`。
记录在恢复时按公开字段重新构建，不将文件里的额外请求头、提示词或反馈编号写入历史库。

## 实现和验证

实现保持在现有单文件聊天页中，没有新增运行依赖或服务端接口。IndexedDB 使用逐条写入事务，
收藏切换在事务中读取最新值，多标签页写入不会用旧列表覆盖新记录。打开历史面板时重新读取数据库。

浏览器回归使用本机模拟后端，执行仓库原始页面，覆盖刷新、快照与导出、搜索与筛选、收藏、
单条删除、批量清理、跨标签页、分页、存储不可用和写入失败恢复，以及 390 像素手机布局。
这些测试验证功能与交互，不衡量模型回答质量，不连接远程 Worker 或付费模型。

```bash
RAG_QA_BROWSER_CHANNEL=chrome uv run --no-sync python tests/browser/public_chat_browser.py -v
```

可用 `RAG_QA_BROWSER_SCREENSHOTS=artifacts/evaluations/history-ui` 保存页面截图；不设置时不写截图。
