# 历史问答、笔记与收藏

日常使用入口为 `rag-qa serve` 的聊天页。页面顶部新增“历史与收藏”，无需额外配置或模型调用。
Streamlit 仍作为调试工作台，本版历史功能只在 FastAPI 聊天页提供。

## 使用

- 选择一本教材或“全部教材”提问，服务完整返回结果后，回答下方显示“已保存到此浏览器”。
- 刷新当前标签页会恢复正在显示的已保存问答；新开标签页默认展示最近十条，完整记录在历史面板中。
- 可搜索问题、回答、教材名、章节和引用原文；空格分隔的多个关键词需要同时匹配。
  列表会展示命中位置附近的文字，并标明回答、笔记、章节或引用；问题本身的命中可直接看标题。
  搜索为空时仍显示原来的回答与笔记预览，不拼接全部正文。
- 教材筛选和“只看收藏”可以与关键词搜索叠加。列表按保存时间倒序，每批显示二十条。
  当前标签页刷新后会恢复筛选条件，也可以点击“清除筛选”回到全部记录。
  选“全部教材”提出的问题在教材筛选里单独归为“跨教材提问”（第一项“全部教材”仍表示不筛选）；
  按某一本教材筛选时不包含它们，即使其中的引用来自这本教材。
- 点击“查看原回答”会显示当时的回答、提示、耗时及引用快照，沿用引用跳转、复制和 Markdown 导出。
  这不会重新检索或生成，即使教材索引发生变化，也仍展示当时保存的公开片段。
- 仅返回教材资料、无证据或失败结果也可以“导出本次记录”，保留问题、提示和已返回的原文，
  并明确写明没有完整生成回答；不会把停止或断流的部分文本当作完整记录导出。
- 收藏按钮可以再次点击取消收藏。“清空对话”只收起当前显示，刷新也会保持收起；记录仍在历史面板中。
  其他标签页先改了收藏时，当前按钮仍按显示的“收藏 / 取消收藏”意图更新，并保留最新笔记与复习信息。
- 单条“删除记录”会删除问答及引用快照。“清理记录”可批量删除未收藏记录，或删除包括收藏在内的全部记录。
  删除前有确认，删除后无法撤销；筛选条件不会缩小批量清理范围。

## 数据保存位置和范围

问答数据保存在**当前浏览器的网站存储 IndexedDB**，数据库名 `rag-qa-history`，版本 `1`，
对象仓库 `records`。不在项目目录或服务端 SQLite 中保存历史，因此不需要维护新的服务器数据库。
同一浏览器配置下的同一网址来源共享历史；`localhost` 与 `127.0.0.1`、不同端口、不同浏览器或设备
各自独立。同一浏览器配置的使用者都可以查看这些记录，服务访问口令不会隔离本机历史。
同一来源的其他标签页保存、收藏或修改笔记后，当前页会自动重新读取本机历史；
通知只包含“数据有更新”，不传送问答正文或口令。不支持通知通道时，返回标签页也会重新读取。
正在返回答案或写入历史时会先等当前操作结束，不替换提问草稿，也不自动展开其他标签页的新回答。

每条记录包含随机编号、保存时间、问题、教材编号和名称、收藏状态，以及公开结果快照：
回答、状态、提示、引用片段、冲突提示、引用编号检查、耗时和执行位置。
不保存访问口令、请求头、模型提示词或用于提交反馈的短期 `answer_id`；旧记录不再提供反馈按钮。
已返回的“仅教材片段”“无证据”和失败结果也会保存状态；主动停止、网络中断和 SSE 错误留下的部分回答不保存。

当前标签页正在显示的记录编号放在 `sessionStorage` 的 `rag-qa-visible-history` 中；
它只控制刷新时显示哪些记录，不包含问答正文。既有访问口令和教材选择仍使用原来的会话存储。

浏览器无痕模式、网站存储限制、磁盘空间不足或清除网站数据都可能影响保存。读取失败时页面会提示，
仍允许提问；写入失败时回答下方会明确显示“未能保存历史记录”，提供重试保存及原有的 Markdown 导出。
写入已经提交、只是随后读取列表失败时，会保留“已保存”状态并提示重试读取，不重复写入旧快照。
笔记、收藏更新和备份恢复也按事务是否提交显示结果；列表刷新失败不会要求重做已完成的操作。
重要问答可以单独导出包含引用的 Markdown，也可以使用“备份与恢复”下载完整 JSON 备份。
本版没有自动跨设备同步。
备份校验组件未加载时，页面会明确停用备份与恢复并提示刷新；已有历史和逐题 Markdown 导出仍可使用。

## 整库备份与恢复

在历史面板展开“备份与恢复”，可备份全部记录，或只备份当前关键词、教材和收藏筛选的结果。
导出的 JSON 包含问答、引用、收藏和来源位置，不包含访问口令、模型提示词或短期反馈编号。
文件下载到浏览器选择的位置，可以手动复制到另一台设备恢复。

选择 JSON 备份后先校验并预览记录数量，点击“确认合并恢复”才会写入。相同编号保留当前浏览器版本，
不会覆盖已有回答或收藏状态；重复恢复不会产生副本。单次最多 5000 条、64 MB，记录较多时按教材筛选分批备份。
无效记录、重复编号、不支持的备份版本会拒绝整批文件；写入采用单个事务，空间不足等失败不会留下半份新增记录。
“未回答”状态却带有答案正文、或下次复习时间不晚于上次自评的矛盾记录也会拒绝；旧版空回答按无回答恢复。
备份本身不认证回答质量或来源真实性，请只导入自己信任的文件。

备份格式为 `format="rag-qa-history"`、`version=2`、`exported_at` 和 `records`，兼容恢复 `version=1` 的旧备份。
记录在恢复时按公开字段重新构建，不将文件里的额外请求头、提示词或反馈编号写入历史库。

## 按筛选整理为 Markdown

在“历史与收藏”设置教材、关键词、“只看收藏”或“有学习笔记”，点击“导出筛选结果（Markdown）”。
文件包含全部匹配问答，按保存时间倒序排列，不限于屏幕上的二十条；每条带教材、保存时间、收藏状态、
已安排的下次复习日期、回答、核对提示、引用原文及已保存笔记。

导出时重新读取已保存内容，不混入编辑器里的草稿，也不改动记录或复习进度，不调用模型。
如果读取期间切换了筛选，文件仍按点击导出时的条件整理。
单次最多 5000 条、64 MB，超过时请按教材或关键词分批导出；读取失败可重试，不会下载不完整文件。
下载后请确认文件已保存。Markdown 用于阅读、打印和整理复习资料，需要恢复到浏览器时仍使用 JSON 备份。
即使 JSON 备份组件加载失败，Markdown 整理仍可使用。

勾选“练习版”后，文件先列出全部问题及作答位置，再集中列出对应的已保存回答、笔记和教材引用。
可以先回忆作答，再向后翻看原记录核对；没有完整回答的记录仍按原状态注明，不会补写答案。
练习版沿用当前筛选与导出上限，不修改复习进度；当前标签页刷新后记住格式选择。

## 学习笔记

每条记录都可以添加学习笔记，最多 4000 字，用来写自己的理解、疑问和复习要点。
点击“保存笔记”后写入当前浏览器；回答及教材快照不改动。历史搜索会检索笔记，也可以勾选“有学习笔记”。
已提交的笔记即使遇到列表读取故障，也会显示保存成功，并允许在同一编辑器继续修改。
Markdown 导出和 JSON 备份都会带上已保存的笔记；旧备份没有笔记字段时按空笔记恢复。

未保存的草稿临时放在当前标签页的会话存储中，刷新后重新打开笔记可以继续编辑；关闭编辑也不删除草稿。
会话存储被禁用或标签页关闭后，草稿不保证保留，重要内容应点击保存。
如果当前草稿暂存失败，页面会明确提示；切换、清空或关闭编辑时可以取消，浏览器支持时刷新也会提醒。
先保存笔记或导出草稿后再离开；暂存恢复后回到正常操作。复习自评遇到这类未保存草稿时先不记次，保存或导出后可继续。
多个标签页编辑同一条笔记时，保存会检查原版本；有冲突时保留最新已保存笔记及当前草稿，
可以点击“把最新笔记加入草稿”，把最新已保存内容追加到当前文字，再自行整理重复内容并保存。
加入草稿只读取最新记录，点击“保存笔记”才会写入；整理期间另一页再次修改，保存仍会检测冲突。
两份内容合计超过 4000 字时，保留原草稿和已保存版本，请先删减草稿或导出后整理。
读取失败可重试，问答已经删除时仍保留原草稿供导出；刷新后恢复的冲突草稿也可继续整理。
恢复草稿仍按原编辑版本检查，不会因为关闭编辑器或刷新就让旧草稿直接覆盖新笔记。
在当前页确认删除记录时，也会清掉它的笔记草稿；“清空对话”只收起显示，仍保留记录和草稿。
如果记录是在其他页面删除，而当前仍打开着笔记编辑器，会保留正在编辑的内容并提示。
此时可以“导出草稿（含原问答）”，保存当前文字及原问题、回答和引用；关闭编辑后才收起已删除记录。
原先的保存提示也会改为“记录已删除，仅在本页暂存”，避免误以为它仍在历史库中。
这种临时保留不会重新创建已经删除的历史，刷新也无法从历史恢复，请先导出。
对已删除记录中尚未导出的非空草稿，切换记录、清空或关闭编辑时会确认；可以取消并继续导出。
浏览器支持时，刷新或离开页面也会给出原生提醒。导出后若继续修改，需要再次导出或确认放弃；
普通记录暂存正常时，编辑和关闭不增加这些确认。导出只是交给浏览器下载，请确认文件已经保存。
正常记录也可随时导出尚未保存的笔记草稿；常规历史备份只包含已保存的笔记。

## 提问草稿与编辑原问题

输入框尚未发送的文字会临时保存在当前标签页，刷新后恢复；发送成功进入请求流程时清掉旧草稿。
等待回答期间继续写下一题，下一题草稿会保留，不会被上一题的完成事件覆盖。
每条已保存的问答还有“编辑原问题”，只把原问题和教材载入输入框，修改后仍需自己点击发送。
原教材暂时不可用时会保留问题、提示重新加载或选择教材，不悄悄改成另一门课，也不会自动提交。
跨教材提问的记录同样恢复为“全部教材”；如果当前只剩一本教材有索引，页面不再提供这个范围，按原教材不可用处理。

如果提问草稿暂存失败，会提示当前文字只在本页；浏览器支持时，刷新或离开页面前会提醒。
可先复制文字保存，或发送问题；恢复暂存、清空输入或发送后不再为这份草稿提醒。
等待上一题回答时继续写下一题，下一题的失败提示和刷新保护仍保留。
这些草稿放在会话存储中，关闭标签页或禁用网站存储后不保证保留。每次提问仍独立检索，
历史记录、笔记和之前的回答不会自动作为新一轮模型上下文发送。

## 实现和验证

交互使用现有聊天页和独立的格式、备份校验脚本，没有新增运行依赖或服务端历史数据库。
IndexedDB 的问答与收藏使用逐条写入事务，备份合并使用整批事务；
收藏切换在事务中读取最新值，多标签页写入不会用旧列表覆盖新记录。打开历史面板时重新读取数据库。

浏览器回归使用本机模拟后端，执行仓库原始页面，覆盖刷新、快照与导出、搜索与筛选、收藏、
单条删除、批量清理、跨标签页、分页、存储不可用和写入失败恢复，以及 390 像素手机布局。
这些测试验证功能与交互，不衡量模型回答质量，不连接远程 Worker 或付费模型。

```bash
RAG_QA_BROWSER_CHANNEL=chrome uv run --no-sync python tests/browser/public_chat_browser.py -v
```

可用 `RAG_QA_BROWSER_SCREENSHOTS=artifacts/evaluations/history-ui` 保存页面截图；不设置时不写截图。
