# 对照教材原文

在聊天页点击回答中的资料编号，或回答下的“对照原文”，即可打开原文面板。
桌面并排显示回答与原文；手机使用“回答 / 原文”按钮切换。可以选择不同资料，查看当时实际引用的快照。
历史记录也可直接打开快照，不需要重新提问。

“读取相邻原文”从当前索引读取定位片段和前后各一个片段；“向前阅读 / 向后阅读”继续按教材顺序移动。
这些操作不调用 LLM、Embedding 或 Reranker，也不改变这次回答的生成依据。
原文以索引中的文本展示，当前不渲染 PDF 页面、图片或数学公式。

新问答保存原文位置和完整定位片段的 SHA-256。读取当前索引时，若定位片段已经变化，页面会显示
“教材原文已更新”，并保留上方的旧快照。旧历史没有位置时仍能查看快照；没有指纹时会提示无法核对版本。
片段已删除、服务暂时不可用或访问口令不正确，都不会覆盖旧快照。

接口为 `GET /v1/books/{book_id}/passages?chunk_id=...`，沿用 `X-Access-Code`，不支持文件路径参数。
读取走索引发布快照边界，避免新旧索引混读；公开响应只包含教材正文、章节、位置和指纹。
读取限流与提问独立，默认每个窗口 60 次；若提问限额更高，则为其六倍，不消耗每日生成额度。

本地验证使用假后端及真实 Chrome：检查桌面并排、手机切换、旧历史、相邻片段导航、更新提示和读取失败恢复。
本轮完整离线测试 631 项中 620 项通过、11 项因缺少 RAGAS eval 依赖跳过，浏览器测试 35 项通过。
