## 引用核对的输入与停止

离线复现：来源编号为 `true` 或重复编号时，原实现仍返回 `checked` 并执行两次核对请求；重复编号会覆盖前面的片段。现在问题、草稿、来源列表和每个来源先检查，编号必须是唯一正整数，正文必须是非空字符串。无效输入返回核对阻断，调用次数为零。模型返回的证据只保留编号和原文摘录。

另一个复现是在非流式草稿生成后请求停止，系统仍继续两次引用核对并返回成功。现在草稿返回后和每次核对请求的前后均检查停止信号；停止作为取消异常传出，不改成核对失败，也不释放草稿或已核对答案。草稿已发送时继续保留 `request_sent=True`，避免额度被错误退还。已在途请求仍须等待返回，不能声称能撤回远端计费。

LLM、查询分解、引用核对和公开 API 的定向回归：92 项通过，111 个子测试通过。Ruff 和差异格式检查通过。新增检查覆盖来源编号、无效输入不发请求、各核对阶段停止、引擎取消状态，以及显式编号 7 不被重新编号。没有真实模型调用，也没有远程 Worker 请求。
