# 2026-10-10 本地迭代

用户续办工程改进；Tailscale 已关闭。本次从提交 `c6e203d` 的干净工作区开始，只使用本地代码、测试替身和已保存开发资料。上一轮最新提交的 16 项 CI 已全部成功。原教材、原索引、冻结验收输入和历史实验产物保留。

## 引用核对的输入与停止

离线复现：来源编号为 `true` 或重复编号时，原实现仍返回 `checked` 并执行两次核对请求；重复编号会覆盖前面的片段。现在问题、草稿、来源列表和每个来源先检查，编号必须是唯一正整数，正文必须是非空字符串。无效输入返回核对阻断，调用次数为零。模型返回的证据只保留编号和原文摘录。

另一个复现是在非流式草稿生成后请求停止，系统仍继续两次引用核对并返回成功。现在草稿返回后和每次核对请求的前后均检查停止信号；停止作为取消异常传出，不改成核对失败，也不释放草稿或已核对答案。草稿已发送时继续保留 `request_sent=True`，避免额度被错误退还。已在途请求仍须等待返回，不能声称能撤回远端计费。

LLM、查询分解、引用核对和公开 API 的定向回归：92 项通过，111 个子测试通过。Ruff 和差异格式检查通过。新增检查覆盖来源编号、无效输入不发请求、各核对阶段停止、引擎取消状态，以及显式编号 7 不被重新编号。没有真实模型调用，也没有远程 Worker 请求。

## 核对 JSON 歧义

离线复现了一份同时含 `"supported":false` 和 `"supported":true` 的判定，原解析器取最后一个值，最后返回 `checked`。现在两阶段核对 JSON 均拒绝重复字段与非 JSON 数值常量，避免同一来源或判定被静默覆盖；歧义陈述不会进入第二次请求，歧义判定不会发布答案。17 项引用核对回归通过，20 个子测试通过。这个修复只涉及实验性产品引用核对，不修改评测器 v5 或任何冻结结果，也不代表模型语义判断已获验证。

## 复制答案恢复

Chrome 离线复现了复制回退后按钮焦点丢失。原本剪贴板接口拒绝时不会尝试本地选择回退；选择复制抛异常时清理语句也会被跳过。现在保留操作前焦点，始终移除临时输入框，剪贴板接口拒绝后尝试本地复制，最终失败时明确提示手动复制。问答保存入口仍可用。

公开页 18 项本地 Chrome 回归通过，新增三项验证无剪贴板接口、接口拒绝、复制异常、焦点、下一题草稿与教材选择保留，问答和反馈请求数不增加。测试使用隔离剪贴板替身，不读取或改写用户的系统剪贴板。

实际手机浏览器在 390 像素尺寸检查存档回答的复制、保存与下一题草稿布局，截图 `public-copy-mobile-20261010.jpg` 位于原本的忽略产物目录。手动检查只浏览与导航，未点击复制或发送新模型请求；截图不是效果评分。

## 评估页异常记录

用四条本地示例记录复现：正常分数 0.8、正负无穷和布尔值混在一起时，原页面平均值显示 `nan`，把布尔值计作有效分数，过滤后还会遗漏记录。现在非有限数值与布尔值均归为未评分，不纳入平均值，默认过滤仍保留这些记录；原结果表不被改写。布尔值整列也能正确显示零条有效分数。

缺失题号原本会使页面报错；重复、布尔或小数题号还可能被显示为错误的原题序号。现在只有唯一正整数题号才显示 Q 编号，异常时图表与明细按结果行编号显示，并保留原题号、提示不能据此配对题目。行号按数字排序。20 项网页流程与打包定向回归通过，8 个子测试通过；全套本地 pytest 退出码为 0，Ruff 与差异格式检查通过。
