## 代码变化

`scripts/replay_context_expansion.py` 新增 `bridge_parent` 离线方案。先找实际交付来源中标题与问题词重叠最多的来源；仅当它的正文明确提到一个问题里没有的概念、相邻片段的小节标题包含该概念、且正文开头正在解释它时，优先取开头最多两个完整段落。找到这种概念后，同一二级节中允许以问题词选择最多三个连续段落；其余情况沿用原来的最多两段选择。

规则没有 Cache／栈专用词表，也不读取开发诊断行号。仍然限制新增正文 1200 字符、来源 8 份、总上下文 4000 字符，保留基线来源及编号，不跨教材或二级节边界，不截半段。

`rag/supplement.py` 另过滤三类实际遇到的非解释段落：带可识别函数声明的未加围栏 C 代码、只有显示公式的段落，以及图片文件名被截断后剩下的哈希路径与图注。内联公式与解释文字仍可选。这里是保守的段落识别，不是支持任意语言和损坏格式的完整解析器。

回放报告增加辅助实现文件的 SHA-256，覆盖打包、段落规则、分词、索引排序和覆盖计算；原有脚本与输入哈希继续保留。以上规则和新提示词均为开发实验，产品默认流程未改变。
