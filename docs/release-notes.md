# 小版本记录

## 0.2.1 · 学习笔记

- 问答记录可保存个人笔记，支持笔记搜索、筛选、Markdown 导出和 JSON 备份。
- 当前标签页保留编辑草稿；跨标签页修改冲突会提示，不静默覆盖最新笔记。
- 修正查看历史后收藏按钮的状态同步，以及手机点击靠后引用时的原文面板定位。
- 49 项真实 Chrome 页面回归通过，覆盖保存、草稿、清空笔记、并发编辑和手机定位。

## 0.2.0 · 个人学习工作流

- 历史问答自动保存在当前浏览器，刷新可恢复，支持关键词、教材和收藏筛选、单条删除与批量清理。
- 增加完整 JSON 备份及校验后的合并恢复；相同编号保留当前版本，写入失败整批回滚。
- 回答与引用原文并排阅读，手机切换查看，可按顺序读取当前索引的相邻片段；原文变化会提示。
- 检索观察台展示实际关键词、向量、融合、重排和最终上下文，不调用生成模型。
- 本机教材导入支持 Markdown 和分块 JSON：先预览、再确认、显示实际批次进度，刷新可恢复查看。
- 所有实验性生成与上下文策略继续保持原默认状态。

使用入口为 `rag-qa serve`。历史与备份在浏览器侧；导入来源和进度在服务机器的 `product/imports/`。
Streamlit 继续用作调试工作台。导入向导第一版不在页面内解析 PDF，也不提供任意新教材命名。

本轮使用本地模拟模型、真实 Chroma 临时索引及真实 Chrome 页面验证，不连接远程 Worker、不调用付费模型。
