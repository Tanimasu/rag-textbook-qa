  单本、全库、观察台、分解和 HyDE 的检索部分及独立向量检索都走该实现；Worker 协议不变。
- dev 35 题对三个独立旧基线，四策略 Top-5、Recall/MRR/nDCG 均零变化；Recall 和倒数排名精确符号检验均 p=1。
  MPS 上 65 题四策略、5 个独立进程逐题一致；全库 dev 35 题、3 个独立进程一致，单线程 BLAS 对照也一致。
  冻结查询复查精确列表稳定，同批原始 Chroma 仍有两种结果。
- 最终 65 题只计分一次，Recall@5 为 0.708 / 0.815 / 0.831 / 0.908（BM25 / Embedding / Hybrid / 重排）；
  重排 MRR 0.718、nDCG@5 0.602。汉明码现在稳定未命中，保留历史一命中、两未命中的证据，不把消抖当召回提升。
- 五道开发题每范围各重复 3 次（每组每范围 15 次），旧/新语义中位数 / p90：单本 3.99 / 6.42 →
  1.91 / 4.06 毫秒，全库 29.27 / 35.23 → 9.66 / 13.51 毫秒。
  端到端单本 0.430 / 0.586 → 0.465 / 0.692 秒，全库 1.933 / 3.259 → 1.994 / 2.502 秒；
  **端到端中位数变慢**，模型阶段时差及输入审计见[性能记录](retrieval-performance.md)，没有减少候选。
- 5700 × 1024 矩阵占 22.27 MiB；整体刷新中位数新增约 0.148 秒（各 3 次）。
  预热普通刷新后的 RSS 增加 31.48 MiB，未预热普通分配器的原始增加值 160.47 MiB 也保留。
  单本 20,000 块矩阵估算 78.125 MiB，非真实导入峰值验收；没有阈值或近似回退。
- 已发布索引、题集和历史报告保持只读。离线注入 provider 覆盖原子刷新、暴力参考、同分、坏向量及全库嵌入次数。
  未运行付费生成、真实 HyDE、真实远程 Worker、CPU/CUDA 真实模型确定性或回答质量验收。
  证据：`artifacts/evaluations/exact-semantic-20261113/`，详见[根因与修复](evaluation-methodology.md#跨进程抖动的根因与修复)。

## 0.3.39 · MPS 重排按实测批大小提速

- 未显式设置 `RAG_QA_RERANK_BATCH_SIZE` 时，MPS 自动用 8，CPU/CUDA 保留 32；已有显式配置（包括 32）优先。
  保留单本 15 / 五本全库 75 个候选、原生 512 tokens 和 float32。
- 本机 MPS 同进程交替配对：五道开发题各重复 3 次，每组每范围 15 次。单本中位数 / p90 从
  0.803 / 0.850 降到 0.567 / 0.731 秒；全库从 3.250 / 3.419 降到 2.789 / 2.937 秒（中位数约降 14%）。
- dev 35 题及最终一次 65 题配对确认，单本和全库的候选池、逐题 Top-5 都零变化；没有减少候选。
  这不是跨进程消抖验收，Chroma 的已知抖动仍在。分开进程的全库计时反而变慢，原数与配对依据见[性能记录](retrieval-performance.md)。
- 新增默认关闭的本机长度 / 精度开关：长度 384 改变单本 23/35、全库 22/35 题；长度 256 两条路线均改变 28/35 题；
  float16 两条路线均改变 4/35 题。它们各自与 batch 32 对照，不把组合效果当成已测结果。
- 非默认长度、精度进入模型指纹；remote 客户端及 `worker serve` 明确拒绝这些覆盖项。
  分词复用仅省约 0.124 毫秒，没有增加默认缓存。未验证其他设备提速、真实 Worker、回答质量或长度/精度组合效果。

## 0.3.37 · Worker 离线时不再让每个问题等两分半

- 连接远程 Worker 单独限时，默认 5 秒（`RAG_QA_REMOTE_CONNECT_TIMEOUT`）；等待推理结果仍用
  `RAG_QA_REMOTE_TIMEOUT`。此前两者共用 120 秒，对端离线时要等操作系统约 75 秒才放弃连接。
- 启用查询回退时，一次瞬时故障后 60 秒内（`RAG_QA_REMOTE_COOLDOWN`，`0` 关闭）直接使用本地模型，
  到期再试远程；Embedding 和 Reranker 共用这份记录。
- Worker 离线、启用回退的 Mac 上各测一轮：只检索的问题从每题约 150 秒变为第一题 12.3 秒、随后每题 0.6 秒。
- 认证失败、模型指纹不一致和协议错误仍直接报错，不触发冷却；索引构建和评测不回退，也不受冷却影响。

## 0.3.36 · 可选关闭回答思考，缩短首字等待

- 新增 `LLM_DISABLE_THINKING=true`：回答生成不再先做隐藏推理。默认不设，行为不变。
- 五道开发题实测（同一提示词各调用一次）：首字平均 18.7 秒降到 1.1 秒，整段回答 30.7 秒降到 9.7 秒，
  输出 token 平均 1232 降到 376。
- 只对已验证的 SiliconFlow `deepseek-ai/DeepSeek-V4-Pro` 发送该参数；其他服务或模型不发送，并在启动时提示。
- 关闭后的回答平均短约两成，回答质量没有评测，所以是可选项而不是默认值。
