# 小版本记录

## 0.3.16 · 页面组件故障提示

- 备份组件未加载时，明确提示刷新并停用备份与恢复，不再显示程序内部的属性读取错误。
- 组件故障不影响已有历史、继续提问、原文快照和逐题 Markdown 导出。
- 80 项真实 Chrome 页面测试通过。

## 0.3.15 · 按本地日期复习

- “明天 / 一周后复习”从目标日期零点起到期，晚上评分后次日早晨即可复习。
- 使用固定浏览器时间验证珀斯的一日安排，以及纽约跨夏令时的一周安排，不依赖测试机器时区。

## 0.3.14 · 清空访问口令

- 聊天、检索观察和教材导入页清空口令后同步忘记会话中的旧值，刷新不再恢复已清空的口令。
- 空口令请求也更新本标签页的保存状态，不保留上一次非空值。

## 0.3.13 · 导入故障恢复

- 长文件名保留扩展名，不再因显示名称截断而误拒绝有效 JSON 或 Markdown。
- 索引线程无法启动时释放运行状态，后续导入和原任务重试均可继续，关闭服务也不会尝试等待未启动的线程。
- 索引已发布但完成进度写盘失败时，保留真实完成状态并提示；恢复存储后补写，不重复调用 Embedding。
- 656 项离线测试中 645 项通过、11 项缺少 RAGAS eval 依赖跳过；新增实际 Chroma 发布后故障回归。

## 0.3.12 · 跨标签页更新与草稿保护

- 其他标签页保存、收藏和修改笔记后自动更新当前历史；不支持通知通道时在返回标签页时读取。
- 当前答案返回或历史写入期间延后同步，保留提问和笔记草稿；通知不包含正文或口令。
- 其他页面删除正在编辑的问答时保留当前草稿，可连同原问答导出；关闭编辑后才收起，复习自评暂时停用。

## 0.3.11 · 复习状态一致性

- 复习中打开其他历史记录会先退出复习，避免显示另一题答案却给原题计分。
- 当前记录删除或取消收藏后自动跳过；保存自评前在同一事务中再次检查收藏状态。
- 跨标签页取消收藏后不写入新的复习日期，已复习数量也不会误增。
- 72 项真实 Chrome 页面测试通过；离线测试仍为 652 项中 641 通过、11 项缺少 RAGAS eval 依赖跳过。

## 0.3.10 · 导入预览失败清理

- 预览阶段的分块格式校验失败时，清理本次尚未形成有效任务的上传副本，避免留下页面无法管理的目录。
- 清理只作用于本次新目录；已有任务和索引构建失败后可重试的文件继续保留。
- 离线测试 652 项中 641 项通过、11 项缺少 RAGAS eval 依赖跳过；页面资源沿用已通过 69 项浏览器回归的版本。

## 0.3.9 · 自定义片段定位

- 导入分块使用 UUID 等不含顺序的 ID 时，可以准确读取引用原文。
- 无法确定教材顺序时说明原因并禁用翻页，不使用集合返回顺序猜测相邻片段。
- 离线测试 651 项中 640 项通过、11 项缺少 RAGAS eval 依赖跳过；69 项真实 Chrome 页面测试通过。

## 0.3.8 · 深色与笔记冲突恢复

- 改善深色模式的按钮和错误提示，三张页面在 320 像素窄屏检查通过。
- 修复跨标签笔记冲突后重新打开仍反复冲突的问题；恢复旧草稿时明确提示核对最新笔记。
- 学习笔记保留原始缩进和尾部空白，纯空白内容仍可清空。
- 68 项真实 Chrome 页面测试通过。

## 0.3.7 · 分块输入一致性

- 命令行和页面建索引统一拒绝重复 JSON 字段及非有限数值，避免静默选择重复字段的最后一个值。
- 用实际 Chroma 临时索引验证：异常输入不增加 Embedding 调用、不替换原书，也不改变已发布版本元数据。
- 离线测试 650 项中 639 项通过、11 项缺少 RAGAS eval 依赖跳过。

## 0.3.6 · 资料与未回答记录导出

- 未配置模型、生成额度用完、没有证据或失败的完整返回记录，都可导出为 Markdown。
- 导出明确标注没有完整生成回答，同时保留实际原文和状态提示，不重新请求模型。
- 67 项真实 Chrome 页面测试通过。

## 0.3.5 · 历史状态与渲染整理

- 当前标签页恢复历史筛选，支持一键清除；删除记录同步清理它的笔记草稿。
- 独立整理 Markdown 渲染和备份校验脚本，无新增运行依赖；格式脚本加载失败时仍可安全查看文本和原文快照。
- 页面资源使用固定允许列表，并加入 wheel 发布清单。
- 离线测试 649 项中 638 项通过、11 项缺少 RAGAS eval 依赖跳过；66 项浏览器测试通过。

## 0.3.4 · 提问草稿与编辑

- 提问草稿和教材选择在当前标签页刷新后恢复，发送后清掉旧草稿，等待期间写的下一题保持不变。
- 已保存问答可“编辑原问题”，恢复教材和文字，不自动提交；教材缺失时明确要求重新选择。
- 63 项真实 Chrome 页面测试通过。

## 0.3.3 · 观察取消与公开调用边界

- 检索观察取消后，在当前原生阶段返回时检查停止，不再启动后续模型阶段。
- 公开问答显式关闭实验性相邻上下文，不继承外部引擎对象的实验开关。
- 离线测试 648 项中 637 项通过、11 项缺少 RAGAS eval 依赖跳过。

## 0.3.2 · 表格与代码阅读

- 常用 Markdown 比较表格按列显示，手机可在表格内横向滚动；引用编号仍可定位原文。
- 支持反引号和波浪号代码围栏，独立复制代码；内联代码中的标记按字面保留。
- 收起或清空阅读内容时取消浏览器侧尚未完成的原文请求。
- 59 项真实 Chrome 页面测试通过，已检查手机表格、笔记和复习截图。

## 0.3.1 · 导入任务管理

- 最近导入任务可在新标签页继续查看，结束后可以确认清理上传副本，已发布索引保留。
- 运行中的任务不能清理；更换文件或教材后旧预览失效，慢进度响应也不会重新显示旧预览。
- 增加进度写入失败时旧索引仍保留的真实 Chroma 回归。
- 离线测试 647 项中 636 项通过、11 项缺少 RAGAS eval 依赖跳过；55 项浏览器测试通过。

## 0.3.0 · 收藏复习

- 收藏可以按当前筛选进入每轮最多 20 条的复习，先隐藏回答，再对照原记录，自评后安排 1 天 / 7 天再看。
- 当前标签页刷新可以续接；跳过或退出不改复习日期，不调用模型。
- JSON 备份升级为版本 2，保留笔记和复习信息，继续兼容旧版备份。
- 52 项真实 Chrome 页面测试通过。

## 0.2.1 · 学习笔记

- 问答记录可保存个人笔记，支持笔记搜索、筛选、Markdown 导出和 JSON 备份。
- 当前标签页保留编辑草稿；跨标签页修改冲突会提示，不静默覆盖最新笔记。
- 修正查看历史后收藏按钮的状态同步，以及手机点击靠后引用时的原文面板定位。
- 49 项真实 Chrome 页面回归通过，覆盖保存、草稿、清空笔记、并发编辑和手机定位。

## 0.2.0 · 个人学习工作流

- 历史问答自动保存在当前浏览器，刷新可恢复，支持关键词、教材和收藏筛选、单条删除与批量清理。
- 增加完整 JSON 备份及校验后的合并恢复；相同编号保留当前版本，写入失败整批回滚。
- 回答与引用原文并排阅读，手机切换查看，可按顺序读取当前索引的相邻片段；原文变化会提示。
- 检索观察台展示实际关键词、向量、融合、重排和最终上下文，不调用生成模型。
- 本机教材导入支持 Markdown 和分块 JSON：先预览、再确认、显示实际批次进度，刷新可恢复查看。
- 所有实验性生成与上下文策略继续保持原默认状态。

使用入口为 `rag-qa serve`。历史与备份在浏览器侧；导入来源和进度在服务机器的 `product/imports/`。
Streamlit 继续用作调试工作台。导入向导第一版不在页面内解析 PDF，也不提供任意新教材命名。

本轮使用本地模拟模型、真实 Chroma 临时索引及真实 Chrome 页面验证，不连接远程 Worker、不调用付费模型。
