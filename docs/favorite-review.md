# 复习收藏

在“历史与收藏”中，先按教材、关键词或笔记筛选，再点击“复习收藏”。每轮最多 20 条，默认只选到期的收藏，
没有复习记录的收藏可以直接开始。勾选“包括未到期收藏”可提前复习。

开始后先只显示原问题，试着凭记忆回答，再点击“显示回答与引用”，对照保存的回答、教材片段和自己的笔记。
确认后选择“还不熟 · 明天复习”或“已熟悉 · 一周后复习”。日期按当前浏览器的本地日历计算，
从目标日期零点起即视为到期，不必等到前一次评分的时刻；跨夏令时也按日历日期计算。
下次打开复习时按到期时间筛选；不推送通知，不调用任何模型。

可以跳过问题或结束复习，这两种操作不增加复习次数，也不改下一次日期。当前标签页刷新后会续接本轮问题，
再次隐藏答案，让你先回忆。关闭标签页后本轮队列不保证保留，已完成的复习日期始终在历史库中保存。
复习时暂时收起提问框，结束后恢复；失败历史中的重试按钮在复习期间禁用，以免意外重新调用模型。
从历史列表查看另一条问答或编辑它的笔记，会先退出本轮复习，避免给原来的问题误记复习进度。
当前问题被删除或取消收藏后会跳过；保存自评前也会重新检查记录是否仍被收藏。
使用键盘开始或跳到下一题时，焦点移到“显示回答与引用”；展开后移到回答正文，结束后返回提问框。
如果其他页面删除了当前问题，而你仍在编辑笔记，会先保留草稿并停用自评；导出或关闭编辑后再继续。

这只是按自评安排的简单 1 天 / 7 天复习，不自动判定掌握程度，也不代表回答质量已经过核证。
原问题、回答和引用快照不变。新的 JSON 备份包含复习次数、上次自评、上次时间和下次日期。

备份升级为 `version=2`，以免旧版程序把笔记与复习字段当作未知字段丢弃；当前程序仍可恢复 `version=1` 的旧备份。
浏览器回归覆盖答案隐藏、日期保存、刷新续接、跳过、教材筛选和手机布局；
当前完整检查结果见 [本轮验收](iteration-personal-study-20261017.md)。
